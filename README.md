Твой след — платформа для благоустройства города
Коротко о сервисе:
«Твой след» — это веб-платформа, где жители могут предлагать идеи по улучшению города, обсуждать их в чатах и голосовать за лучшие проекты.

Основной функционал:
- Регистрация и профиль пользователя
- Просмотр новостей проекта
- Интерактивная карта с метками проблемных мест
- Добавление своих идей (с привязкой к адресу на карте)
- Лайки и рейтинг предложений
- Чаты для обсуждения каждой идеи
- Голосование за лучшие проекты через баннер
Технологии: Node.js (Express), SQLite, Яндекс.Карты, HTML/CSS/JS.
